# CMSC 313 Project

## Project Description

A C program that outputs a hex dump of the `data/binary.out` file. The output has the left most column as the number of bytes into the file (i.e. the address) in hex. The middle are 16 consecutive bytes in hex separated by spaces, and the left most column is the ASCII representation of the bytes with ‘.’ replacing any non-ASCII bytes.
The prpject also includes the compiled program with optimisation levels -O0, -O1 and -O3 and a comparison and review of the assembly code generated by the different optimization levels.

## Build Program

To build the program, run from project root:

```bash
gcc -Wall src/hexdump.c -o build/hexdump
```

## Build Assembly

To build the assembly files, run from project root:

```bash
gcc -Wall -O0 -S src/hexdump.c -o asm/hexdump_O0.s
gcc -Wall -O1 -S src/hexdump.c -o asm/hexdump_O1.s
gcc -Wall -O3 -S src/hexdump.c -o asm/hexdump_O3.s
```

## Run

To start the program, run from project root:

```bash
./build/hexdump data/binary.out
```
